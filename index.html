本周情况

约 12 月龄。前半周肚子不舒服时偏养胃安排，现已好转，后半周按正常菜单。午餐软饭按生米约 20–25g，主餐辅食油合计约 5g；奶仍 2 顿约 420ml（~06:00 180ml + ~19:15 240ml）+ 维生素 D 400IU。鱼虾只安排在午餐。奶酪土豆饼周六下午加回。无盐无糖无酱油无生抽。

本周重点 · 新菜与注意

① 周一午餐胡萝卜鲜虾生菜豆腐汤饭一锅出，生菜下锅煮软，不另蒸菜、不放丝瓜。② 周二三文鱼蔬菜软饭以农家菠菜为主，多放一些，焯软切碎再拌饭，不放番茄。③ 周三香蕉常温切小直接吃，不蒸。④ 周三下午原订牛肉小馄饨实际没吃，改到周五下午，本周只这一次。⑤ 周五午餐清蒸野生鳜鱼，买不到则改甜椒牛肉饼（往期作彩椒牛肉饼），搭配水煮生菜和米饭；鳜鱼刺多且细，须彻底去刺，只给肉。⑥ 周六苹果炖鸡翅须彻底去骨（含小骨），只给肉。⑦ 无盐无糖无酱油无生抽。

周一 11.16

苹果山药小米粥 · 胡萝卜鲜虾生菜豆腐汤饭 · 山药茯苓糊糊

鲜虾汤饭 · 养胃

早餐

苹果山药小米粥 + 小馒头

碳水 小米 + 小馒头蔬果 山药 + 蒸苹果蛋白 —脂肪 —
食材
  • 小米约 15g
  • 山药约 15g，去皮切小块，蒸软压泥
  • 苹果约 30g（当天半个蒸苹果，去皮去核，蒸软压泥）
  • 小馒头 1–2 个（可买成品或家做；看配料无盐无糖）
做法
  1. 小米加水煮至软烂，拌入蒸软的山药泥和苹果泥，打细调稀；不加盐糖。
  2. 小馒头撕小块手抓；可略蒸热。

粥须软烂顺滑。本餐苹果即当天的半个蒸苹果，不再另加水果。

午餐

胡萝卜鲜虾生菜豆腐汤饭（一锅出）

碳水 软饭约 20–25g（生米，同锅）蔬菜 胡萝卜 + 生菜（煮软）蛋白 鲜虾 + 嫩豆腐脂肪 辅食油合计约 5g
食材
  • 鲜虾仁约 35–40g，去虾线切小
  • 胡萝卜适量，切小
  • 生菜适量，切碎（下锅煮软，不生吃）
  • 嫩豆腐约 30g，切小丁
  • 软米约 20–25g（生米；同锅煮软或汤泡软）
  • 姜片少许；辅食油合计约 5g；清水；不加盐、酱油、生抽
做法
  1. 一锅出：米与胡萝卜、姜片加水煮至米软、胡萝卜软透。
  2. 下豆腐丁与虾仁，煮至虾全熟变色；生菜碎后下，煮软，不生吃。
  3. 整餐辅食油合计约 5g（不足再补足，勿另加一份 5g）。汤底不加盐、酱油、生抽。鱼虾只午餐。

一锅出，不再另蒸胡萝卜。虾务必全熟切小；生菜下锅煮软。本周不放丝瓜。

下午餐

山药茯苓糊糊（不二宝贝）+ 蛋黄西兰花小饼

碳水 糊糊 + 少量面粉蔬菜 西兰花（少放，焯软）蛋白 蛋黄脂肪 少量油
食材
  • 不二宝贝山药茯苓糊糊 1 份（按包装冲调）
  • 蛋黄 1 个
  • 西兰花适量（少放），焯软切碎
  • 少量面粉 + 少量油；不加盐糖
做法
  1. 不二宝贝山药茯苓糊糊按包装用温水冲开调稀，放温同餐。
  2. 西兰花焯软切碎，与蛋黄、面粉调糊。
  3. 少油小火煎软薄小饼，切条手抓。不加盐糖。

糊糊调稀防呛。小饼少油煎软；西兰花少放、焯软切碎。若仍腹胀，可改普通蔬菜或蒸蛋。

周二 11.17

胚芽米燕麦粥 · 三文鱼蔬菜软饭 · 蒸苹果

三文鱼菠菜软饭

早餐

胚芽米燕麦粥 + 水煮蛋

碳水 胚芽米 + 燕麦蔬菜 —蛋白 全蛋脂肪 —
食材
  • 胚芽米约 10g
  • 即食燕麦约 5–8g
  • 鸡蛋 1 个（全蛋水煮）
做法
  1. 胚芽米先煮软，下燕麦再煮片刻成粥；不加盐糖。
  2. 水煮蛋至全熟，可切小块或捣碎拌粥。

粥须软烂；蛋全熟。当天水果改到下午：半个蒸苹果 + 小馒头。

午餐

三文鱼蔬菜软饭

碳水 软饭约 20–25g（生米）蔬菜 农家菠菜为主（多一些）蛋白 三文鱼约 40–50g脂肪 辅食油合计约 5g
食材
  • 三文鱼约 40–50g，去皮去刺切小
  • 农家菠菜适量（多放一些），去掉根茎老叶
  • 软米约 20–25g（生米）
  • 辅食油合计约 5g；不加盐、酱油、生抽
做法
  1. 三文鱼清蒸或少油炒至全熟，仔细去刺后压碎。
  2. 菠菜焯软切碎，再拌进软饭；本周不放番茄。
  3. 先按生米约 20–25g 煮成软饭，与鱼和菜轻轻拌匀；整餐辅食油合计约 5g（不足再补足，勿另加一份 5g）。不加盐、酱油、生抽。鱼虾只午餐。

三文鱼必须全熟、仔细去刺后压碎。蔬菜以新鲜农家菠菜为主，多一些，焯软切碎再拌饭；叶子新鲜的先用。本周不放番茄。

下午餐

半个蒸苹果 + 小馒头

碳水 小馒头水果 半个蒸苹果蛋白 —脂肪 —
食材
  • 半个苹果，去皮去核，蒸软
  • 小馒头 1–2 个（可买成品或家做；看配料无盐无糖）
做法
  1. 苹果去皮去核，蒸软，切小或压泥，作为当天水果。
  2. 小馒头撕小块手抓；可略蒸热。不加盐糖。

当天水果即这半个蒸苹果，不再另加。市售馒头看配料，含盐含糖不选。

周三 11.18

南瓜小米粥 · 清蒸比目鱼 · 牛肉小馄饨

比目鱼 · 馄饨

早餐

南瓜小米粥 + 常温香蕉

碳水 小米蔬菜 南瓜水果 常温香蕉（几口）脂肪 —
食材
  • 小米约 10–15g
  • 老南瓜约 30g，去皮切小块
  • 香蕉几口，去丝，切小，常温直接吃（不蒸）
做法
  1. 小米与南瓜一起煮至软烂，南瓜压碎拌匀；不加盐糖。
  2. 香蕉去丝，切小，常温直接吃，不蒸。只给几口。

本周香蕉只这一次，常温切小直接吃，不蒸；当天不叠蒸苹果。

午餐

清蒸比目鱼 + 清蒸时蔬 + 软饭（生米约 20–25g）

碳水 软饭约 20–25g蔬菜 青菜或胡萝卜（清蒸）蛋白 比目鱼约 40–50g脂肪 辅食油合计约 5g
食材
  • 比目鱼约 40–50g，去刺确认
  • 姜片；不加盐、酱油、生抽
  • 时蔬适量（蒸软青菜或胡萝卜；不用花菜、芦笋），切小
  • 软米约 20–25g（生米）
做法
  1. 比目鱼放姜片清蒸至全熟易碎，仔细剔刺。
  2. 时蔬同蒸或另蒸至软，切小同餐。
  3. 配软饭：生米约 20–25g 煮软；整餐辅食油合计约 5g（不足再补足，勿另加一份 5g）。
  4. 不加盐、酱油、生抽。鱼虾只午餐。

比目鱼刺务必剔净；软饭生米约 20–25g。时蔬用蒸软青菜或胡萝卜，不用花菜、芦笋。

下午餐

牛肉小馄饨（自包，个数按食量）+ 青菜

碳水 馄饨皮蔬菜 青菜蛋白 牛肉馅脂肪 —
食材
  • 牛肉馅无盐自包（个数按蕉蕉食量）
  • 清水；汤里不加盐/酱油/紫菜虾皮
  • 青菜约 25–30g（小油菜/小青菜等）
做法
  1. 自包牛肉小馄饨下开水，浮起后再煮 2–3 分钟，切开确认全熟。
  2. 青菜焯软切碎。
  3. 全程不加盐、酱油、生抽。市售含盐馄饨不选。

馄饨自包无盐，切开确认全熟；个数按食量。本周牛肉小馄饨只这一次。若当天肚子仍不舒服，可再改为粥类。

周四 11.19

鸡蛋水饼 · 番茄牛尾骨汤 · 山药小黄米馒头

牛尾

早餐

鸡蛋水饼 + 黑芝麻核桃糊糊 + 几颗蓝莓

碳水 少量面粉 + 米水果 几颗蓝莓蛋白 全蛋脂肪 黑芝麻 + 核桃
食材
  • 鸡蛋 1 个（全蛋）
  • 面粉少量 + 温水适量
  • 少量油；不加盐糖
  • 大米或小米约 10–12g
  • 熟黑芝麻碾碎少许
  • 核桃少量
  • 蓝莓几颗，洗净
做法
  1. 全蛋打散加温水、面粉调稀糊，少油小火摊薄水饼，两面熟透，切条。
  2. 米煮软，加黑芝麻与核桃打成细糊，调稀；芝麻核桃须碾细防呛。
  3. 蓝莓洗净，只给几颗，直接吃；不加糖。
  4. 不加盐糖。

蓝莓只给几颗，洗净即可，不加糖。

午餐

番茄牛尾骨汤 + 米饭（生米约 20–25g）

碳水 软饭约 20–25g蔬菜 番茄蛋白 牛尾（软烂剔骨）脂肪 汤油 + 辅食油合计约 5g
食材
  • 牛尾骨适量（可先泡水解冻）
  • 番茄适量，去皮切碎
  • 姜片；清水；不加盐、酱油、生抽
  • 软米约 20–25g（生米）
做法
  1. 牛尾骨泡水焯烫；番茄少油炒出汁，与牛尾、姜片加水小火炖至牛尾软烂。
  2. 肉剔骨后撕碎/切小。整餐辅食油合计约 5g（含汤油；不足再补足，勿另加一份 5g）。
  3. 配米饭：生米约 20–25g 煮软；汤可少许拌饭。
  4. 汤底不加盐酱油生抽。本餐不放土豆。

由往期番茄土豆炖牛尾骨汤改成不放土豆。牛尾须软烂剔骨，只给肉。

下午餐

清蒸玉米笋 + 山药小黄米馒头

碳水 小黄米粉 + 面粉 + 山药蔬菜 玉米笋蛋白 —脂肪 —
食材
  • 玉米笋适量，洗净
  • 山药适量，去皮
  • 小黄米粉、面粉适量
  • 温水适量；不加盐糖
做法
  1. 玉米笋清蒸至软，切小段同餐。
  2. 山药蒸软压泥，与小黄米粉、面粉加少量温水拌成面团，揉匀，分成小剂，做成小馒头。
  3. 上锅蒸至熟透；放温撕小块手抓。不加盐糖。

山药小黄米馒头按食量做几个即可，不另加盐糖；面团软硬用适量米粉和面粉调整，不另估克数。

周五 11.20

红薯杂粮粥 · 清蒸野生鳜鱼 · 牛肉小馄饨

鳜鱼

早餐

红薯杂粮粥 + 水煮蛋 + 蒸胡萝卜

碳水 杂粮 + 红薯蔬菜 胡萝卜蛋白 全蛋脂肪 —
食材
  • 小米/大米/燕麦等杂粮适量
  • 红薯适量，蒸软压泥或切小丁
  • 鸡蛋 1 个（全蛋水煮）
  • 胡萝卜约 30–40g，去皮切条或小块
做法
  1. 杂粮加水煮至软烂，拌入蒸软红薯泥/丁成粥；不加盐糖。
  2. 水煮蛋至全熟，可切小块或捣碎同餐。
  3. 胡萝卜蒸 10–15 分钟至手指可压碎，切手抓条或压碎勺喂。

午餐

清蒸野生鳜鱼 + 水煮生菜 + 米饭（买不到则甜椒牛肉饼）

碳水 软饭约 20–25g蔬菜 水煮生菜 + 甜椒（备选）蛋白 鳜鱼约 40–50g（或甜椒牛肉饼）脂肪 辅食油合计约 5g
食材
  • 野生鳜鱼约 40–50g（首选；刺多且细，须彻底去刺）
  • 姜片；不加盐、酱油、生抽
  • 买不到鳜鱼时改用：牛肉馅约 40–50g
  • 甜椒适量，切细，煮/炒软（往期作彩椒牛肉饼）

  • 水果：不再固定每天半个蒸苹果。本周为：周一早餐粥里蒸苹果、周二下午半个蒸苹果、周三早餐几口常温香蕉（去丝切小直接吃，不蒸，当天不叠蒸苹果）、周四早餐几颗蓝莓、周六午餐苹果炖鸡翅、周六下午蓝莓牛油果酸奶。
  • 鱼虾放午餐：周一鲜虾、周二三文鱼、周三比目鱼、周五鳜鱼均在午餐；虾全熟切小，鱼须全熟、仔细去刺。周五鳜鱼刺多且细，彻底去刺只给肉；买不到则改甜椒牛肉饼（往期作彩椒牛肉饼），甜椒切细煮/炒软。
  • 周一汤饭一锅出：胡萝卜鲜虾生菜豆腐汤饭同锅煮软或汤泡软，不再另蒸胡萝卜；生菜切碎下锅煮软，不生吃；不放丝瓜。
  • 菠菜焯软：周二三文鱼蔬菜软饭以农家菠菜为主，多放一些，去掉根茎老叶，焯软切碎再拌进饭；本周这餐不放番茄。周日芝麻拌菠菜也须焯软，趁温与芝麻拌，别做太凉。
  • 蛋黄西兰花小饼：周一下午少油小火煎软；西兰花少放、焯软切碎。
  • 牛肉小馄饨：周三下午原订没吃，改到周五下午自包无盐，切开确认全熟；个数按食量。本周只这一次。
  • 去骨去刺：周五鳜鱼刺多且细，须彻底去刺，只给肉；周六苹果炖鸡翅须彻底去掉所有骨头（含小骨），只给肉。
  • 周五二选一：午餐买得到就做清蒸野生鳜鱼，买不到则改甜椒牛肉饼。若走到牛肉饼，下午又是馄饨，当天两顿牛肉，可按食量少给或再说一声改下午。
  • 奶与 VitD：奶约 420ml/天分 2 顿（~06:00 约 180ml、~19:15 约 240ml）；维生素 D 400IU/天继续补。周六酸奶和奶酪、周日烘蛋的奶酪/鲜奶不替代配方奶瓶。
  • 食量与观察：按实际食量喂。如有发热、腹泻不止、大便带血、尿明显变少或精神变差，及时就诊。
  • 本页非医疗建议：仅供家庭辅食安排参考；如有生长曲线、肠胃或过敏问题，请咨询儿科医生。
