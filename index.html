蕉蕉的本周辅食计划

2026 年 10 月 19 日（周一）— 10 月 25 日（周日）· 每天早餐、午餐、下午餐三顿

约 11 月龄 · 4 颗牙 · 约 10kg 奶 2 顿约 420ml（~06:00 180ml / ~19:15 240ml）+ VitD 400IU 辅食三餐：早餐 · 午餐 · 下午餐 软米生重约 20–25g · 主餐油约 5g 新引入：茭白 · 芦笋（小份观察） 本周不排蛏子 · 厚蛋烧全蛋重做 1 岁内不加盐、不加糖、不加酱油/生抽
本周情况

约 11 月龄，午餐软饭按生米约 20–25g，主餐辅食油约 5g。奶仍 2 顿约 420ml（~06:00 180ml + ~19:15 240ml）+ 维生素 D 400IU。鱼虾只安排在午餐；下午可红肉/猪肝/蛋。奶酪入菜一般半块；奶酪土豆饼本周一次（周三下午）。

本周重点 · 新食物与注意

① 新引入小份观察：茭白（周二午餐茭白炒肉）、芦笋（周三午餐蒸芦笋，软烂可压碎）。② 本周不排蛏子。③ 葱香厚蛋烧（周六下午）：全蛋重做，葱花极少切末煸熟提香，无盐，小火煎厚、中心全熟。④ 周一午餐牛肉奶酪苹果饼为家里剩，先煎熟再蒸至切开无粉红。⑤ 无盐无糖无酱油无生抽。

要买 / 常备

需买：牛肉馅/剩饼、猪肉末、猪肝、牛尾骨、三文鱼、羊肉、鲜虾、鸡蛋、奶酪、嫩豆腐、茭白、芦笋、西兰花、菠菜、生菜、油麦菜、小油菜、胡萝卜、番茄、山药、土豆、紫薯、红薯、南瓜、玉米、香蕉、蓝莓、牛油果、低筋粉、蝴蝶面、细面/挂面、小米、燕麦、宝宝酸奶、小馒头。常备：米、黑芝麻、核桃、花生、配方奶、辅食油。详见「采购」。

周一 10.19

南瓜小饼 · 牛肉奶酪苹果饼 · 紫薯蒸蛋

南瓜小饼

早餐

南瓜小饼 + 宝宝酸奶

碳水 低筋粉 + 南瓜泥蔬菜/果 南瓜蛋白 蛋 + 宝宝酸奶脂肪 奶 + 少量油
食材
  • 老南瓜适量，蒸软压泥
  • 鸡蛋约 1/2–1 个
  • 低筋面粉适量
  • 配方奶少量调糊
  • 可点黑芝麻少许；少量油；不加糖
  • 宝宝酸奶一小份
做法
  1. 南瓜蒸软压泥，与蛋、低筋粉、少量配方奶调成稠糊；可点黑芝麻。
  2. 少油小火摊成小饼，两面煎透至中心全熟，切条手抓。
  3. 配宝宝酸奶一小份；不加盐糖。

南瓜小饼：南瓜泥+蛋+低筋粉+奶，小火煎透；可点黑芝麻；不加糖。图源小红书；用量以上面蕉蕉分量为准。

午餐

牛肉奶酪苹果饼（家里剩）+ 水煮西兰花 + 软饭约 20–25g

碳水 软饭约 20–25g蔬菜 西兰花蛋白 牛肉馅 + 奶酪（饼内）脂肪 辅食油合计约 5g
食材
  • 家里剩的牛肉奶酪苹果饼（含牛肉馅、奶酪、苹果等）
  • 西兰花适量
  • 软米约 20–25g（生米）
  • 辅食油合计约 5g（含炒/煎用油）；不加盐
做法
  1. 剩饼先少油煎热，再上锅蒸至切开无粉红、中心全熟。
  2. 西兰花水煮/焯至软，切小。
  3. 另煮软饭：生米约 20–25g 煮软；整餐辅食油合计约 5g（含煎用油；不足再补足，勿另加一份 5g）。
  4. 不加盐、酱油、生抽。

家里剩饼：先煎熟、再蒸至切开无粉红。软饭按生米约 20–25g；辅食油合计约 5g。

下午餐

紫薯蒸蛋 + 蓝莓

碳水 紫薯水果 蓝莓蛋白 全蛋脂肪 —
食材
  • 紫薯适量，蒸软压泥/切小丁
  • 鸡蛋 1 个（全蛋）+ 温水约 1.5 倍
  • 蓝莓适量，洗净压碎或切半
做法
  1. 紫薯蒸软压泥或切小丁；蛋打散加温水过筛，拌入紫薯，盖盘小火蒸 10–12 分钟至凝固全熟。
  2. 蓝莓洗净，压碎或对半同餐；不加盐糖。

蛋须蒸至全熟无流心；蓝莓可压碎防呛。

周二 10.20

蓝莓小馒头 · 茭白炒肉（新） · 猪肝菠菜粥

新·茭白

早餐

蓝莓小馒头 + 蒸蛋

碳水 小馒头水果 蓝莓蛋白 全蛋脂肪 —
食材
  • 小馒头 1–2 个
  • 蓝莓适量，洗净压碎或切半（可拌馒头或同餐）
  • 鸡蛋 1 个 + 温水约 1.5 倍
做法
  1. 小馒头撕小块；蓝莓洗净压碎或切半同餐。
  2. 蛋打散加温水过筛，盖盘小火蒸 10–12 分钟至凝固全熟，切小块。
  3. 不加盐糖。

蒸蛋须全熟；蓝莓可压碎。

午餐

茭白炒肉（新菜小份）+ 软米饭约 20–25g

碳水 软饭约 20–25g蔬菜 茭白（新·小份）蛋白 猪肉末脂肪 辅食油合计约 5g
食材
  • 猪肉末约 40–45g
  • 茭白适量（本周新菜，小份），切薄片
  • 辅食油合计约 5g（含炒用油）；不加盐、酱油、生抽
  • 软米约 20–25g（生米）
做法
  1. 少油下猪肉末炒至全熟变色无粉红。
  2. 茭白切薄片，炒/煮至透明软烂；本餐只给小份观察。
  3. 配软饭：生米约 20–25g 煮软；整餐辅食油合计约 5g（含炒用油；不足再补足，勿另加一份 5g）。
  4. 不加盐酱油生抽；观察 2–3 天过敏/肠胃反应。

新食物·茭白：切薄片炒/煮至透明软烂，新菜小份；猪肉末炒至全熟。软饭生米约 20–25g。

下午餐

猪肝菠菜粥

碳水 大米约 15–20g蔬菜 菠菜约 30–40g蛋白 猪肝约 15–20g脂肪 辅食油合计约 5g
食材
  • 猪肝约 15–20g，去筋膜
  • 菠菜约 30–40g
  • 大米约 15–20g
  • 姜片少许；辅食油合计约 5g；不加盐
做法
  1. 猪肝冷水浸泡去血水，焯烫后剁细。
  2. 大米先煮至半烂，下猪肝末煮至全熟。
  3. 菠菜焯水切碎后下锅，煮成偏稀粥；整餐辅食油合计约 5g（不足再补足，勿另加一份 5g）。
  4. 不加盐、酱油、生抽。

猪肝务必全熟；本周主力补铁餐之一。鱼虾只午餐，下午可红肉/猪肝/蛋。

周三 10.21

香蕉鸡蛋饼 · 番茄虾仁蝴蝶面+芦笋（新） · 奶酪土豆饼

新·芦笋

早餐

香蕉鸡蛋饼 + 黑芝麻核桃米糊

碳水 面粉 + 米水果 香蕉蛋白 全蛋脂肪 黑芝麻 + 核桃 + 少量油
食材
  • 香蕉适量压泥
  • 鸡蛋 1 个（全蛋）
  • 面粉少量 + 少量油；不加盐糖
  • 大米或小米约 10–12g
  • 熟黑芝麻碾碎少许
  • 核桃少量
做法
  1. 全蛋打散，加香蕉泥、少量面粉调成糊，少油小火摊成小饼，两面煎熟，切条。
  2. 米煮软，加黑芝麻与核桃打成细糊，调稀；芝麻核桃须碾细防呛。
  3. 不加盐糖。

香蕉鸡蛋饼用全蛋；糊要细、无颗粒。

午餐

番茄虾仁蝴蝶面 + 蒸芦笋（新菜小份）

碳水 蝴蝶面蔬菜 番茄 + 芦笋（新·小份）蛋白 鲜虾仁脂肪 辅食油合计约 5g
食材
  • 鲜虾仁约 35–40g，去虾线切小
  • 番茄适量去皮切碎
  • 蝴蝶面适量煮软
  • 辅食油合计约 5g（含炒用油）；不加盐、酱油、生抽
  • 芦笋适量（本周新菜，小份），去老根切小段
做法
  1. 少油炒番茄出汁，下虾仁炒至全熟变色，拌入煮软蝴蝶面；整餐辅食油合计约 5g（含炒用油；不足再补足，勿另加一份 5g）。
  2. 芦笋切小段蒸至软烂可压碎；本餐只给小份观察。
  3. 不加盐酱油生抽；虾务必全熟。
  4. 观察 2–3 天过敏/肠胃反应。

新食物·芦笋：蒸至软烂可压碎，新菜小份。鱼虾只午餐。不加盐酱油。

下午餐

奶酪土豆饼（奶酪半块）

碳水 土豆 + 少量面粉蛋白 蛋黄 + 奶酪半块脂肪 少量油
食材
  • 土豆适量，蒸软压泥
  • 蛋黄 1 个（或全蛋，按食量）
  • 奶酪半块，切碎
  • 面粉少量、葱花少许
  • 少量油；不加盐
做法
  1. 土豆蒸软压泥，加蛋黄、奶酪碎（半块）、面粉、葱花拌匀成稠糊。
  2. 少油小火摊成小饼，两面煎熟，切条手抓。
  3. 不加盐、酱油、生抽。

奶酪一般半块；本周奶酪土豆饼仅此一次（每周一次）。

周四 10.22

鸡蛋水饼 · 三文鱼时蔬烩饭 · 香蕉牛油果燕麦片拌酸奶

三文鱼

早餐

鸡蛋水饼 + 玉米山药米糊

碳水 面粉 + 米 + 玉米 + 山药蛋白 全蛋脂肪 少量油
食材
  • 鸡蛋 1 个（全蛋）
  • 面粉少量 + 温水适量
  • 少量油；不加盐糖
  • 大米或小米约 10–12g
  • 玉米粒适量
  • 山药约 15–20g，去皮切小块
做法
  1. 全蛋打散加温水、面粉调稀糊，少油小火摊薄水饼，两面熟透，切条。
  2. 米与山药加水煮软，下玉米再煮片刻，压碎打细成糊，调稀。
  3. 不加盐糖。

水饼须熟透；糊可压碎调稀。

午餐

三文鱼时蔬烩饭（三文鱼约 40–50g，奶酪半块拌入，生米约 20–25g）

碳水 软饭约 20–25g蔬菜 时蔬（胡萝卜/西兰花/玉米等）蛋白 三文鱼约 40–50g + 奶酪半块脂肪 DHA + 辅食油合计约 5g
食材
  • 三文鱼约 40–50g，去皮去刺切小丁
  • 软米约 20–25g（生米）
  • 时蔬丁（胡萝卜、西兰花、玉米等）适量
  • 奶酪半块，切碎拌入
  • 辅食油合计约 5g（含炒用油）；不加盐、任何调味
做法
  1. 少油下三文鱼丁炒至全熟变色，下时蔬丁翻软。
  2. 先按生米约 20–25g 煮成软饭，再与鱼蔬轻轻烩匀，拌入奶酪半块；整餐辅食油合计约 5g（含炒用油；不足再补足，勿另加一份 5g）。
  3. 仔细确认无刺；不加盐、酱油、生抽。

三文鱼必须全熟去刺（去皮去刺）；奶酪半块拌入；生米约 20–25g，辅食油合计约 5g。鱼虾只午餐。

下午餐

香蕉牛油果燕麦片拌酸奶（混合，非纯酸奶）

碳水 燕麦片水果 香蕉 + 牛油果蛋白 宝宝酸奶脂肪 牛油果
食材
  • 香蕉适量压泥
  • 牛油果适量压泥
  • 即食燕麦片约 8–10g（可先用温水/配方奶泡软）
  • 宝宝酸奶适量（与以上混合，非纯酸奶一大杯）
做法
  1. 燕麦片用温水或少量配方奶泡软。
  2. 香蕉、牛油果压泥，与燕麦、宝宝酸奶拌匀成稠糊/拌餐。
  3. 不加糖；现拌现吃。

混合餐，非纯酸奶；牛油果现压现吃。

周五 10.23

蓝莓松饼 · 胡萝卜炖牛尾骨 · 时蔬奶酪燕麦烘蛋

蓝莓松饼 · 牛尾

早餐

蓝莓松饼 + 杂粮粥

碳水 低筋面粉约 15–20g + 杂粮水果 蓝莓约 20–25g蛋白 蛋约 1/2–1脂肪 配方奶约 30ml + 少量油
食材
  • 蓝莓约 20–25g
  • 鸡蛋约 1/2–1 个
  • 配方奶约 30ml
  • 低筋面粉约 15–20g
  • 少量油；不加盐糖
  • 小米/大米/燕麦等杂粮适量煮粥
做法
  1. 蛋、配方奶、蓝莓入辅食机搅打约 3 分钟至体积约 1.5 倍。
  2. 加入低筋面粉搅拌至无干粉颗粒。
  3. 不粘锅最小火，舀一勺面糊摊成 2–3 片；表面冒泡后翻面，两面煎熟。
  4. 另煮杂粮粥至软烂，可压碎调稀；不加盐糖。

蓝莓松饼：蓝莓约 20–25g、蛋约 1/2–1、配方奶约 30ml、低筋粉约 15–20g，做 2–3 片。配杂粮粥。

午餐

胡萝卜炖牛尾骨 + 软饭（生米约 20–25g）+ 蒸生菜

碳水 软饭约 20–25g蔬菜 胡萝卜 + 生菜蛋白 牛尾（软烂剔骨）脂肪 汤油 + 辅食油合计约 5g
食材
  • 牛尾骨适量（可先泡水解冻）
  • 胡萝卜切块
  • 姜片；清水；不加盐、酱油、生抽
  • 软米约 20–25g（生米）
  • 生菜适量
做法
  1. 牛尾骨泡水焯烫；与胡萝卜、姜片加水小火炖至牛尾软烂、胡萝卜软透。
  2. 肉剔骨后撕碎/切小；汤底不加盐。整餐辅食油合计约 5g（含汤油；不足再补足，勿另加一份 5g）。
  3. 配软饭（生米约 20–25g 煮成）；汤可少许拌饭。
  4. 生菜蒸/焯至软，切小同餐。

  • 即食燕麦约 8–10g
  • 奶酪半块切碎

  • 不放肉末；不加盐

  2. 倒入耐烤模具，烤箱/空气炸烤至表面凝固、中心全熟。
  3. 放温切小块；不加盐糖酱油。

不放肉末；烤箱/空气炸至中心全熟；奶酪半块。中心无流心再喂。

周六 10.24

清汤羊肉 · 厚蛋烧

早餐

蒸红薯小米粥 + 蒸胡萝卜

碳水 小米 + 红薯蔬菜 胡萝卜蛋白 —脂肪 —
食材
  • 小米约 10–12g
  • 红薯适量，蒸软压泥或切小丁
  • 胡萝卜约 30–40g，去皮切条或小块
做法
  1. 小米加水煮至软烂，拌入蒸软红薯泥/丁成粥；不加盐糖。
  2. 胡萝卜蒸 10–15 分钟至手指可压碎，切手抓条或压碎勺喂。

午餐

清汤羊肉 + 水煮油麦菜 + 软米饭约 20–25g

食材
  • 羊肉约 40–50g（熟肉量；或带骨炖软后撕碎）
  • 姜片；辅食油合计约 5g（含炒/炖用油）；不加盐、酱油、生抽
  • 油麦菜适量，焯/水煮至软，切小
  • 软米约 20–25g（生米）
做法
  1. 羊肉切小块清水炖至软烂，撕碎适合约 11 月龄；汤底无盐。
  2. 油麦菜焯/水煮至软烂，切小。
  3. 配软饭：生米约 20–25g 煮软；整餐辅食油合计约 5g（含炒/炖用油；不足再补足，勿另加一份 5g）。
  4. 不加盐、酱油、生抽。

羊肉炖至软烂撕碎；汤底无盐；软饭生米约 20–25g。

下午餐

葱香厚蛋烧（全蛋）

周日 10.25

  • 清水；不加盐、酱油、生抽、糖
  • 青菜少许（如小油菜叶），焯软切碎

  1. 细面下开水煮至很软，可切短段；汤底清水无盐。
