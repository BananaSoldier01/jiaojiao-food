本周情况

碳水略减、蔬菜略增周：主食标"少量"的约 10–15g，蔬菜每天约 60–80g，肉鱼虾每天约 35–45g。周一已吃（香菇鸡腿肉饭 + 芝麻蛋黄小饼/花生糊）。周六上午饭菜分离；周日下午再试燕麦香蕉酸奶。

本周重点

① 蛋白轮换：鸡 / 虾×2 / 三文鱼 / 牛 / 猪肉馄饨 / 排骨 / 蛋；② 本周无猪肝，铁靠牛肉 + 猪肉 + 虾 + 三文鱼；③ 咀嚼：馄饨、蝴蝶面、馒头、鸡蛋玉子烧、虾丸、排骨撕碎、藕块；④ 过敏观察：花生（周一）、豆浆（周三）、酸奶再试（周日）；⑤ 一天不叠两个水果，全程不加盐糖酱油。

要买 / 常备

需买：虾仁、三文鱼、牛肉、猪小排、鸡蛋、冬瓜、西兰花、口蘑、洋葱、玉米、小油菜、西葫芦、番茄、土豆、莲藕、南瓜、菠菜馒头、香橙、苹果、雪梨、香蕉、原味酸奶、黄豆、银耳、燕麦、蝴蝶面。常备：米、小米、山药、胡萝卜、小馒头、猪肉小馄饨存货、配方奶。详见「采购」。

周一 9.28

已吃 · 香菇鸡腿日

已吃 ✓

上午 · 正餐 · 10:30 · 已吃

香菇鸡腿肉饭（已吃）

碳水 软米饭蔬菜 香菇 + 胡萝卜蛋白 鸡腿肉脂肪 少量油
食材
  • 鸡腿肉约 35–40g，去皮去骨切小丁
  • 香菇 1–2 朵切碎；胡萝卜少量切小粒
  • 软米约 15g（煮成软饭）
  • 姜片、少量油（不加盐、不加生抽）
做法
  1. 鸡腿肉丁加姜片抓匀略腌去腥。
  2. 少油炒香菇、胡萝卜粒，下鸡丁炒至变色。
  3. 与淘好的米加水焖成软饭，鸡肉软烂。
  4. 出锅剪碎、拌匀；不加任何调味。

本日已吃。鸡肉为本周早间蛋白第一站。

下午 · 轻餐 · 16:30 · 已吃

香蕉芝麻蛋黄小饼 + 红枣红豆核桃花生糊（已吃）

碳水 面粉 + 红豆水果 香蕉蛋白 蛋黄脂肪 芝麻 + 核桃 + 花生
食材
  • 香蕉半根压泥
  • 蛋黄 1 个（全熟）
  • 面粉少量、熟黑芝麻碾碎少许
  • 红枣（去核）、红豆、核桃、花生，煮烂打细糊
做法
  1. 香蕉泥 + 蛋黄 + 面粉 + 芝麻碎调糊，少油小火煎软薄小饼。
  2. 红豆提前泡软，与去核红枣、核桃、花生煮烂后打成细糊，调稀。
  3. 小饼切小条手抓；糊用勺喂。
  4. 不加糖。

⚠ 花生过敏观察：已吃，留意 2–3 天内口周红疹、呕吐等反应。

周二 9.29

冬瓜虾丸汤 · 少量软米饭

虾丸汤

上午 · 正餐 · 10:30

冬瓜虾丸汤（山药胡萝卜虾丸）+ 少量软米饭 + 西兰花

碳水 少量软米饭 + 山药蔬菜 冬瓜 + 胡萝卜 + 西兰花蛋白 虾仁脂肪 少量
食材
  • 虾仁约 35–40g，去虾线
  • 山药约 15g、胡萝卜约 10g（打泥入虾丸）
  • 冬瓜约 30g，去皮切小块
  • 西兰花约 20g，取小花
  • 软米饭约 10–15g（少量）
做法
  1. 虾仁、山药、胡萝卜一起打成细滑虾泥，不加盐。
  2. 冬瓜加水煮开后转小火，用勺挤小虾丸下锅，煮至虾丸浮起全熟。
  3. 西兰花焯软切碎。
  4. 汤、虾丸、少量软米饭、西兰花分开摆，虾丸可切小块手抓。

本周"少碳水"：软米饭只少量，蔬菜冬瓜 + 西兰花补足；虾丸挤小、煮透。

下午 · 轻餐 · 16:30

菠菜馒头 + 香橙蛋羹

碳水 菠菜馒头蔬菜 菠菜（馒头里）水果 香橙蛋白 鸡蛋
食材
  • 菠菜馒头 1 个（约 15–20g）
  • 鸡蛋 1 个
  • 香橙汁约 20–30ml（现榨过滤）
  • 温水适量
做法
  1. 鸡蛋打散，加橙汁和温水（蛋液:液体约 1:1.5）搅匀，过筛撇去浮沫。
  2. 盖盘或保鲜膜扎孔，水开后中小火蒸约 8–10 分钟至凝固嫩滑。
  3. 菠菜馒头撕小块或切条手抓。
  4. 不加糖。

当天水果只香橙；蛋羹须蒸至全熟无流动蛋液。

周三 9.30

小红书步骤 · 奶香三文鱼

深海鱼日

上午 · 正餐 · 10:30

奶香三文鱼蝴蝶面

碳水 蝴蝶面蔬菜 口蘑 + 洋葱 + 玉米 + 西兰花蛋白 三文鱼脂肪 DHA + 配方奶
食材
  • 三文鱼约 35–40g，去皮去刺切小丁
  • 蝴蝶面约 15g（干重，煮软）
  • 口蘑 1–2 个切小丁；洋葱约 10g 切碎；玉米粒约 10g
  • 西兰花约 15g 切碎
  • 配方奶 100ml（按平时比例冲好）
  • 少量油；不加盐、不加任何调味
做法
  1. 蝴蝶面提前煮软捞出备用。
  2. 锅中少油，洋葱碎炒至变色（软、透明）。
  3. 下三文鱼丁炒至全熟变色。
  4. 口蘑、玉米、西兰花碎先焯水，再下锅一起翻炒。
  5. 倒入配方奶 100ml 和煮好的蝴蝶面，大火收汁至浓稠裹面即可。

步骤按小红书图；家里调味规则：不加盐、不加任何调味。玉米粒可压扁或剪碎防呛。

下午 · 轻餐 · 16:30

苹果山药饼 + 原味豆浆小半杯

碳水 山药 + 少量面粉水果 苹果（熟）蛋白 豆浆脂肪 少量油
食材
  • 苹果约 30g，擦丝或切碎
  • 山药约 30g，蒸软压泥
  • 面粉少量（或加 1 个蛋黄调糊）
  • 黄豆少量，自打原味豆浆 60–80ml
做法
  1. 苹果丝与山药泥、少量面粉拌匀成团，压成小饼。
  2. 少油小火两面煎软熟，切小条手抓。
  3. 黄豆泡发后自打豆浆，过滤，煮沸后再小火煮 5 分钟以上确保煮透。
  4. 豆浆放温后给小半杯（约 60–80ml），不加糖。

⚠ 豆浆（大豆）观察：首次量少，留意皮疹、腹泻、呕吐；豆浆不替代奶。

周四 10.1

国庆 · 红肉补铁

牛肉日

上午 · 正餐 · 10:30

番茄土豆炖牛肉 + 少量软饭

碳水 土豆 + 少量软饭蔬菜 番茄蛋白 牛肉脂肪 少量油
食材
  • 牛肉（牛腩或牛腱）约 35–40g，切小块
  • 番茄约 30g，去皮切碎
  • 土豆约 20g，切小丁
  • 软饭约 10–15g（少量）
  • 姜片
做法
  1. 牛肉冷水下锅焯水，捞出洗净。
  2. 番茄少油炒出汁，加牛肉、姜片和热水，小火炖约 1 小时。
  3. 加土豆丁再炖 20 分钟至牛肉手指可压碎、土豆软烂。
  4. 牛肉切成约 0.5–1cm 小块，配少量软饭。不加盐。

土豆已算部分主食，所以软饭只少量；牛肉是本周主要补铁来源。

下午 · 轻餐 · 16:30

南瓜小米粥 + 时蔬蛋黄小饼

碳水 小米蔬菜 南瓜 + 时蔬蛋白 蛋黄脂肪 少量油
食材
  • 小米约 10–15g
  • 老南瓜约 30g，切小块
  • 蛋黄 1 个 + 少量面粉
  • 时蔬碎（胡萝卜/小油菜等）约 15g
做法

  2. 时蔬焯软切碎，与蛋黄、面粉调糊。
  3. 少油小火煎软薄小饼，切条手抓。
  4. 不加盐糖。

下午蛋白由蛋黄承担；今天无水果，南瓜补甜味。

周五 10.2

冷冻存货 · 咀嚼练习

馄饨日

上午 · 正餐 · 10:30

猪肉小馄饨（冷冻存货）+ 小油菜碎

碳水 馄饨皮蔬菜 小油菜蛋白 猪肉馅脂肪 少量
食材
  • 猪肉小馄饨（冷冻存货）13 个
  • 小油菜约 25g
做法
  1. 冷冻馄饨直接下开水，煮至全部浮起再煮 2–3 分钟，切开确认馅全熟。
  2. 小油菜焯软切碎，放馄饨汤里或另碟。
  3. 馄饨可对半切开，让蕉蕉练咀嚼。
  4. 汤里不加盐、酱油、紫菜虾皮调料。

存货若是自包无盐馅最佳；市售成品馄饨多含盐，建议只用自家包的。

下午 · 轻餐 · 16:30

苹果胡萝卜山药米糊 + 小馒头

碳水 米 + 山药 + 小馒头蔬菜 胡萝卜水果 苹果（熟）蛋白 —
食材
  • 苹果约 30g
  • 胡萝卜约 15g
  • 山药约 20g
  • 大米约 10g
  • 小馒头 1–2 个
做法
  1. 苹果、胡萝卜、山药切小块，与大米一起煮软。
  2. 用料理机打成稍稠米糊（可保留少许细颗粒）。
  3. 小馒头撕小块手抓。
  4. 不加糖。

当天水果只苹果（煮熟入糊）；下午偏轻，蛋白已由上午猪肉承担。

周六 10.3

饭菜分离练习 · 虾丸单独吃

饭菜分离

上午 · 正餐 · 10:30

【饭菜分离】清炒小瓜（西葫芦）+ 番茄虾丸 + 软米饭

碳水 软米饭蔬菜 西葫芦 + 番茄蛋白 虾仁脂肪 少量油
食材
  • 虾仁约 35–40g（可加少量山药泥打虾丸）
  • 番茄约 25g，去皮切碎
  • 西葫芦约 30g，切小条或薄片
  • 软米饭约 15g
做法
  1. 虾仁打泥挤小丸子，煮熟。
  2. 番茄少油炒出汁，下虾丸裹匀番茄汁煮 1–2 分钟。
  3. 西葫芦少油清炒至软（不加盐）。
  4. 三样分别装碟：虾丸单独一碟，不拌进饭；小瓜一碟；软米饭一碟。

本周饭菜分离练习：虾丸单独吃，不拌饭，让蕉蕉分别认识每种食物的口感。

下午 · 轻餐 · 16:30

雪梨银耳羹 + 葱香鸡蛋玉子烧

碳水 玉子烧水果 雪梨蛋白 鸡蛋脂肪 少量油
食材
  • 雪梨约 40g，去皮去核切小块
  • 银耳少量，泡发撕碎
  • 鸡蛋 1 个 + 葱花少许
做法
  1. 银耳泡发撕碎，与雪梨小火炖至软糯，银耳尽量炖出胶。
  2. 鸡蛋打散，加入葱花和少量温水调匀，不加盐、酱油、糖。
  3. 平底锅刷薄油，小火倒入一层薄蛋液，半凝固后从一端卷起推到锅边；再补少量油，倒入少量蛋液与玉子烧底部相连，半凝固后继续卷，重复至蛋液用完，形成层层玉子烧。
  4. 不加盐、酱油、糖。

当天水果只雪梨；玉子烧须全熟，切段大小适合手抓。

周日 10.4

莲藕排骨 · 酸奶再试

排骨日

上午 · 正餐 · 10:30

莲藕炖排骨 + 西兰花 + 少量米饭

碳水 莲藕 + 少量米饭蔬菜 西兰花蛋白 排骨肉脂肪 排骨汤
食材
  • 猪小排 2–3 块（拆肉约 35–40g）
  • 莲藕约 30g，切小块
  • 西兰花约 20g
  • 米饭约 10–15g（少量）
  • 姜片
做法
  1. 排骨冷水下锅焯水洗净。
  2. 排骨、藕块、姜片加水，小火炖约 1.5 小时至藕软糯、肉脱骨。
  3. 排骨肉拆下撕碎，确认无碎骨；藕块切小块。
  4. 西兰花焯软切碎，配少量米饭。不加盐。

务必拆骨撕碎、检查碎骨；藕块炖软即可练咀嚼。

下午 · 轻餐 · 16:30

燕麦香蕉酸奶（再试）+ 小馒头

碳水 燕麦 + 小馒头水果 香蕉蛋白 酸奶脂肪 —
食材
  • 原味无糖酸奶约 40–60g（少量再试）
  • 香蕉约 1/3 根压泥
  • 即食燕麦约 5–8g，热水泡软
  • 小馒头 1 个
做法
  1. 燕麦用热水泡软放凉。
  2. 香蕉压泥，与燕麦、酸奶拌匀。
  3. 小馒头撕小块手抓。
  4. 不加糖；不爱就不强喂。

再试：纯酸奶上次不爱，这次拌香蕉燕麦看能否接受；留意乳制品反应。当天水果只香蕉。

注意事项

  • 本周主题：碳水略减、蔬菜略增——标"少量"的主食约 10–15g，蔬菜每天约 60–80g；按蕉蕉实际食量增减。
  • 过敏观察：周一花生（已吃，观察 2–3 天）、周三豆浆（首次小半杯）、周日酸奶再试；新食物出现皮疹、呕吐、腹泻即停并就医。
  • 饭菜分离：周六上午番茄虾丸单独一碟，不拌进饭；小瓜、软米饭各一碟。
  • 咀嚼进阶：馄饨对半切、蝴蝶面、馒头条、鸡蛋玉子烧段、虾丸、排骨肉撕碎、藕块；坐姿、全程看护。
  • 排骨：周日拆肉撕碎，仔细检查碎骨；藕块炖软切小。
  • 三文鱼蝴蝶面：周三按小红书图的步骤做，但不加盐、不加任何调味；配方奶 100ml 收汁。
  • 豆浆：自打无糖，务必煮沸后再小火煮透；只给 60–80ml，不替代奶。
  • 酸奶：周日是有意再试——纯酸奶不爱，这次拌香蕉燕麦；不爱就不强喂。
  • 铁：本周没有猪肝，靠牛肉、猪肉、虾、三文鱼；下周可考虑安排一次猪肝。
  • 苹果：本周苹果在苹果山药饼和米糊里，都是熟的；平时也可生吃薄条。一天不安排两个水果。
  • 无盐无糖无酱油：不加盐、糖、酱油、生抽，也不用婴儿盐/婴儿酱油；成品馄饨注意看配料。
  • 维生素 D 400IU/天继续补；奶量维持约 600ml。本页仅供参考，不构成医疗建议。
