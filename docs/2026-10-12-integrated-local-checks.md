# 四页整合：本地验收与交接

本记录描述 2026-10-12 发布前完成的本地整合和测试，基线为 `8464673`；不单独证明线上发布状态。

## 实现

- 六个 Tab 保持不变。食谱逐日选择餐次，再切换食材/步骤；按原 HTML 读取两餐或三餐，不硬编码菜名。
- 做法图可放大，原图说明保留；食材与采购勾选只在当前页面会话保留。
- 采购分类与条目兼容旧表格，同时支持模板的明确列表项。
- 营养重点在源 HTML 中填写；旧菜单不生成摘要、不套用本周数字。全部原文保留在对照区。
- 提醒显式分组，未知/未填分组回退为其他提醒或当周提醒；不丢弃条目。
- 首页今日卡片和搜索结果可直达餐次；原日期锚点保持兼容。
- 往期按月份展示。最早只有总览的归档补齐返回/搜索导航，不虚构食谱。
