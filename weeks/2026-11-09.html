周一 11.9

南瓜山药小黄米粥 · 猪肝洋葱胡萝卜玉米粒烩饭 · 番茄面疙瘩

猪肝烩饭

早餐

南瓜山药小黄米粥 + 1个鸡蛋 + 3颗黑莓

碳水 小黄米粥蔬果 南瓜 + 山药 + 黑莓 3 颗蛋白 鸡蛋 1 个脂肪 —
食材
  • 南瓜，去皮切小块（记录未写用量）
  • 山药，去皮切小块（记录未写用量）
  • 小黄米（记录未写用量）
  • 鸡蛋 1 个
  • 黑莓 3 颗，洗净
做法
  1. 小黄米与南瓜、山药加水煮至软烂，压碎或打细；不加盐糖。
  2. 鸡蛋煮至全熟，可切小或捣碎同餐。
  3. 黑莓洗净，可切半或压碎防呛。

粥须软烂。南瓜、山药、小黄米记录未写用量，不补造克数。

午餐

猪肝洋葱胡萝卜玉米粒烩饭（胚芽米25g + 猪肝30g）

碳水 胚芽米 25g（生重）蔬菜 洋葱 + 胡萝卜 + 玉米粒蛋白 猪肝 30g脂肪 —
食材
  • 胚芽米 25g（生重）
  • 猪肝 30g，去筋膜
  • 洋葱、胡萝卜、玉米粒（记录未写用量）
  • 不加盐、酱油、生抽
做法
  1. 猪肝冷水浸泡去血水，焯烫后切小或剁细。
  2. 胚芽米 25g 煮成软饭；洋葱、胡萝卜、玉米粒煮软或炒软，与猪肝烩入软饭，猪肝须全熟。
  3. 不加盐、酱油、生抽。

用量以记录为准：胚芽米 25g、猪肝 30g。猪肝务必全熟。

下午餐

番茄面疙瘩（番茄30g + 面疙瘩30g）+ 2块排骨肉 + 青菜碎 + 芦笋

碳水 面疙瘩 30g蔬菜 番茄 30g + 青菜碎 + 芦笋蛋白 排骨肉 2 块脂肪 —
食材
  • 番茄 30g，去皮切碎
  • 面疙瘩 30g
  • 排骨肉 2 块
  • 青菜碎（记录未写用量）

  3. 青菜焯软切碎。
  4. 芦笋切小段，蒸或焯软至可压碎。

  3. 全程不加盐、酱油、生抽。
