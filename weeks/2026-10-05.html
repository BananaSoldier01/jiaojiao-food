蕉蕉的本周辅食计划

2026 年 10 月 5 日（周一）— 10 月 11 日（周日）· 每天早餐、午餐、下午餐三顿

约 11 月龄 · 4 颗牙 · 约 10kg 奶 2 顿约 420ml（~06:00 180ml / ~19:15 240ml） 辅食三餐：早餐 · 午餐 · 下午餐 谷类略减 · 蔬菜+蛋白略增 蛋白排敏引入 1 岁内不加盐、不加糖、不加酱油
本周情况

自本周起固定三餐（早餐 / 午餐 / 下午餐），奶改为 2 顿：~06:00 约 180ml、~19:15 约 240ml，合计约 420ml/天（原 3 顿约 600ml）。份量主题：谷类略减、蔬菜与肉鱼蛋略增。周一已吃（奶酪土豆饼：蛋黄1个+小圆奶酪一整块；番茄鸡蛋蝴蝶面；外出清水火锅）。蛋白引入：周二约 1/4 单独 → 周三约半个单独 → 周四起全蛋（周四鸡蛋水饼，周五玉米饼，周六、周日早餐水煮全蛋）。周日下午猪肝菠菜粥补铁；周五下午南瓜百合双米粥减少叠蛋；香蕉仅周三早、橙子仅周日早。

本周重点

① 蛋白排敏：周二 1/4、周三 1/2 单独给，周四起全蛋（周六、周日早餐水煮全蛋）；② 蛋白轮换：鸡腿 / 猪肉丸 / 牛肉饼 / 猪肝 / 三文鱼 / 鲜虾 / 鳕鱼 / 蛋；③ 无盐无糖无酱油无生抽；④ 不安排酸奶、本周无蓝莓；⑤ 橙子只在周日早餐两瓣，下午不叠柑橘；⑥ 香蕉只在周三早餐。

要买 / 常备

需买：鸡腿、牛肉馅、猪肝、三文鱼、鲜虾、鳕鱼、鸡蛋、奶酪、土豆、番茄、口蘑、西兰花、南瓜、山药、胡萝卜、芋艿、生菜、娃娃菜、小油菜、菠菜、玉米、菠菜馒头、香蕉、雪梨、苹果、橙子、红枣、黑米、花生、百合、银耳、燕麦、蝴蝶面、低筋面粉、胚芽米。常备：米、小米、小馒头、无盐猪肉小馄饨冻货、配方奶、黑芝麻、核桃。详见「采购」。

周一 10.5

已吃 · 奶酪土豆饼日

已吃 ✓

早餐 · 已吃

奶酪土豆饼（已吃）

碳水 土豆 + 面粉蔬菜 葱花蛋白 蛋黄 + 奶酪脂肪 少量油
食材
  • 土豆适量，蒸软压泥
  • 蛋黄 1 个
  • 小圆奶酪一整块，切碎
  • 面粉少量
  • 葱花少许
  • 少量油；不加盐
做法
  1. 土豆蒸软压泥，加蛋黄、小圆奶酪碎（一整块）、面粉、葱花拌匀成稠糊。
  2. 少油小火摊成小饼，两面煎熟。
  3. 切小条手抓；不加盐、酱油、生抽。

本日已吃。实际：蛋黄 1 个 + 小圆奶酪一整块（非整块鸡蛋）。

午餐 · 已吃

番茄鸡蛋 + 口蘑 + 西兰花 + 蝴蝶面（已吃）

碳水 蝴蝶面蔬菜 番茄 + 口蘑 + 西兰花蛋白 鸡蛋脂肪 少量油
食材
  • 鸡蛋 1 个
  • 番茄适量去皮切碎
  • 口蘑切小丁
  • 西兰花小花焯软切碎
  • 蝴蝶面煮软
  • 少量油；不加盐、酱油、生抽
做法
  1. 少油炒番茄出汁，下口蘑翻炒。
  2. 倒入打散蛋液炒熟。
  3. 拌入煮软蝴蝶面与西兰花碎。
  4. 全程不加盐糖酱油。

本日已吃。

下午餐 · 已吃

清水火锅（外出 · 已吃）

碳水 随餐蔬菜 随餐蛋白 随餐脂肪 —
食材
  • 外出清水火锅，自选软烂蔬菜与熟透蛋白

  3. 按蕉蕉实际食量取用。

本日已吃 · 外出。

周二 10.6

蛋白排敏 · 鸡腿饭

蛋白 1/4

早餐

南瓜山药小米粥 + 水煮蛋蛋白约 1/4（单独排敏）

碳水 小米 + 山药蔬菜 南瓜蛋白 蛋黄可拌粥 · 蛋白单独脂肪 —
食材
  • 小米约 10–15g
  • 老南瓜约 10–15g 切小块
  • 山药约 15–20g 切小块
  • 鸡蛋 1 个（蛋黄可拌进粥；蛋白约 1/4 单独给）
做法
  1. 小米、南瓜、山药加水煮至软烂，南瓜山药可压碎拌匀。
  2. 另锅水煮蛋至全熟，剥壳。
  3. 蛋黄可捣碎拌进粥；蛋白取约 1/4 单独给，观察过敏。
  4. 不加盐糖。

⚠ 蛋白排敏：今日约 1/4 个单独吃，留意 2–3 天内皮疹、呕吐、腹泻；蛋黄可照常拌粥。

午餐

胡萝卜口蘑鸡腿饭

碳水 软米饭（略少）蔬菜 胡萝卜 + 口蘑蛋白 鸡腿肉脂肪 少量油
食材
  • 鸡腿肉约 40–50g，去皮去骨切小丁
  • 胡萝卜约 25–30g 切小粒
  • 口蘑 2–3 个切小丁
  • 软米约 10–15g（略少）
  • 姜片、少量油；不加盐、生抽
做法
  1. 鸡丁加姜片略抓匀。
  2. 少油炒胡萝卜、口蘑，下鸡丁炒至全熟变色。
  3. 与淘好的米加水焖成软饭，鸡肉软烂。
  4. 出锅剪碎拌匀；不加任何调味。

主食略减，蔬菜 + 鸡腿蛋白加量；鸡肉全熟软烂。

下午餐

菠菜馒头 + 黑芝麻核桃红枣糊

碳水 菠菜馒头蔬菜 菠菜（馒头里）蛋白 —脂肪 芝麻 + 核桃
食材
  • 菠菜馒头 1 个（约 15–20g）
  • 熟黑芝麻碾碎少许
  • 核桃少量
  • 红枣（去核）适量，煮软
做法
  1. 红枣去核与核桃煮软，加黑芝麻打成细糊，调稀。
  2. 菠菜馒头撕小块或切条手抓。
  3. 糊用勺喂；不加糖。

下午偏轻；当天无水果叠加。芝麻核桃须碾细防呛。

周三 10.7

蛋白约半个 · 芋艿肉丸

蛋白 1/2

早餐

奶香鸡蛋香蕉燕麦糊（蛋白约半个单独排敏）

碳水 燕麦水果 香蕉蛋白 蛋黄可淋糊 · 蛋白单独脂肪 配方奶
食材
  • 即食燕麦约 10–15g
  • 香蕉半根压泥
  • 配方奶适量
  • 鸡蛋 1 个（蛋黄可淋进糊；蛋白约半个单独）
做法
  1. 水开下燕麦煮软。
  2. 香蕉压泥拌入，再倒入配方奶搅拌防糊底。
  3. 淋入蛋黄液搅拌至熟；蛋白约半个单独蒸/水煮全熟后给。
  4. 不加糖。

⚠ 蛋白排敏：今日约半个单独吃；步骤：水开→燕麦煮软→香蕉→配方奶→搅拌防糊底→淋蛋液。本周香蕉只安排在周三早餐。

午餐

蒸芋艿肉丸 + 少量软饭约 10g

碳水 少量软饭约 10g + 芋艿蔬菜 —蛋白 猪肉末脂肪 少量
食材
  • 猪肉末约 40–45g
  • 芋艿约 30–40g 蒸软
  • 软米约 10g（少量）
  • 葱姜少许；不加盐
做法
  1. 芋艿蒸软压泥，与猪肉末、葱姜搅打上劲，搓小丸。
  2. 上锅蒸至肉丸全熟（切开无粉红）。
  3. 配少量软饭约 10g。
  4. 不加盐、酱油、生抽。

芋艿分担部分碳水，软饭只约 10g；肉丸务必蒸透。

下午餐

雪梨百合银耳汤 + 蔬菜小饼

碳水 少量面粉蔬菜 菠菜或小油菜约 20g水果 雪梨蛋白 —
食材
  • 雪梨约 40g 去皮去核切小块
  • 鲜百合约 10g（撕瓣蒸软）
  • 银耳少量泡发撕碎
  • 菠菜或小油菜约 20g，焯软切碎
  • 少量面粉 + 少量油
做法
  1. 银耳与雪梨小火炖至软糯出胶，百合蒸软后加入。
  2. 菠菜或小油菜约 20g 焯软切碎，与面粉调糊，少油小火煎软薄小饼，切条。
  3. 不加糖盐。

当天水果只雪梨；百合蒸软压碎；小饼用菠菜或小油菜约 20g。无酸奶、无蓝莓。

周四 10.8

全蛋起 · 花生米糊 · 牛肉饼 · 小馒头蒸胡萝卜

全蛋

早餐

鸡蛋水饼（全蛋）+ 花生黑米山药米糊

碳水 面粉 + 黑米 + 山药蛋白 全蛋 + 花生脂肪 少量油 + 花生
食材
  • 鸡蛋 1 个（全蛋）
  • 面粉少量 + 温水适量
  • 黑米约 8–10g，提前泡 2 小时以上
  • 山药约 20g，去皮切小块
  • 熟花生约 5–8g，去红衣
  • 少量油；不加盐、不加糖
做法
  1. 全蛋打散，加温水、面粉调成稀糊，少油小火摊成薄水饼，两面熟透。
  2. 黑米泡软后加水煮至软烂开花，加山药再煮软。
  3. 加熟花生，用料理机打成很细的米糊，不留颗粒；按需加温水调稀。
  4. 水饼切条手抓；米糊放温后勺喂。不加盐、不加糖。

自今日起吃全蛋（蛋黄 + 蛋白一起），水饼须熟透。⚠ 花生过敏观察：9.28 那周已吃过花生，这次仍留意 2–3 天内口周红疹、呕吐、腹泻等反应；花生必须打成细糊，不给整粒或碎粒，防呛。

午餐

苹果奶酪牛肉饼 + 清炒生菜 + 软米饭

碳水 软米饭（略少）+ 淀粉蔬菜 生菜 + 洋葱水果 苹果（熟）蛋白 牛肉馅 + 奶酪
食材
  • 牛肉馅约 40–50g
  • 苹果适量切丁
  • 洋葱切丁
  • 奶酪半块
  • 淀粉少许 + 辅食油
  • 生菜适量
  • 软米约 10–15g
  • 不加盐
做法
  1. 苹果洋葱切丁 + 牛肉馅 + 奶酪半块 + 淀粉 + 辅食油搅打上劲。
  2. 模具压饼，少油小火两面煎熟（切开无粉红）。
  3. 生菜少油清炒至软。
  4. 配少量软米饭。不加盐。

苹果入馅增湿软（当天苹果只在午餐饼里）；牛肉全熟。主食略减，菜+肉加量。

下午餐

小馒头 + 蒸胡萝卜

碳水 小馒头蔬菜 胡萝卜蛋白 —脂肪 —
食材
  • 小馒头 1–2 个
  • 胡萝卜约 40g，去皮切条或小块
做法
  1. 胡萝卜蒸 10–15 分钟至手指可压碎。
  2. 切成手抓条，或压碎勺喂。
  3. 小馒头撕小块手抓。
  4. 不加盐、不加糖。

本周主力补铁餐：猪肝量少、务必全熟；米少菜多。下午无苹果。橙子仍只在周日早餐两瓣。

周五 10.9

玉米饼（小份）· 三文鱼 · 南瓜百合粥

三文鱼

早餐

奶香玉米饼（蕉蕉 2–3 片）

碳水 低筋面粉 + 玉米（蕉蕉份约 15–20g 面粉）蛋白 全蛋 + 配方奶脂肪 少量油 + 黑芝麻
食材
  • 整批：低筋面粉 50g、配方奶 100ml、脱皮玉米 60g、鸡蛋 1 个
  • 蕉蕉份：只给 2–3 片（约合面粉 15–20g）；其余大人吃
  • 黑芝麻少许
  • 少量油；不加盐糖
做法
  1. 玉米 + 配方奶打匀 → 加蛋、面粉拌成糊。
  2. 刷油小火挤糊摊饼，撒黑芝麻后翻面至熟。
  3. 蕉蕉只吃 2–3 片，余量大人吃。
  4. 不加盐、不加糖。

整批照做，蕉蕉只吃 2–3 片，其余大人吃。本餐不配豆浆。无酸奶。

午餐

奶酪口蘑三文鱼蝴蝶面

碳水 蝴蝶面（略少）蔬菜 口蘑蛋白 三文鱼 + 奶酪脂肪 DHA + 少量油
食材
  • 三文鱼约 40–50g，去皮去刺切小丁
  • 蝴蝶面约 12–15g（干重）
  • 口蘑 2–3 个切小丁
  • 奶酪半块
  • 少量油；不加盐、任何调味
做法
  1. 蝴蝶面煮软捞出。
  2. 少油下三文鱼丁炒至全熟变色，下口蘑翻炒。
  3. 加奶酪半块与蝴蝶面轻轻拌匀收汁。
  4. 不加盐、酱油、生抽。

三文鱼必须全熟去刺；主食略减，鱼+菜为主。

下午餐

南瓜百合双米粥

碳水 大米 + 小米（少量）蔬菜 老南瓜 + 鲜百合蛋白 —脂肪 —
食材
  • 老南瓜约 40g，去皮切小块
  • 鲜百合约 10g，撕瓣洗净
  • 大米约 5g + 小米约 5g（双米合计约 10g，少量）
  • 清水适量；不加盐、不加糖
做法
  1. 大米、小米淘净，加水先煮 15 分钟至开花。
  2. 下南瓜块煮至软烂，压碎拌匀。
  3. 下鲜百合再煮 5–8 分钟至软糯，百合可压碎。
  4. 煮成稍稠的粥，放温后勺喂；不加盐、不加糖。

低碳水：双米合计只约 10g，南瓜和百合占大头。下午不叠蛋；周五无香蕉。

周六 10.10

鲜虾豆腐汤 · 小馄饨

鲜虾

早餐

苹果山药小米粥 + 水煮蛋（全蛋）

碳水 小米 + 山药水果 苹果（熟）蛋白 水煮蛋（全蛋）脂肪 —
食材
  • 小米约 10–15g
  • 山药约 20–25g
  • 苹果约 30g 切小块
  • 鸡蛋 1 个（全蛋，水煮全熟）
做法
  1. 小米、山药、苹果一起煮至软烂，压碎拌匀。
  2. 水煮蛋全熟，整个蛋（蛋黄 + 蛋白）切小块手抓，或捣碎拌进粥。
  3. 不加糖盐。

由周四下午挪到这里；鸡蛋给全蛋。当天水果只苹果。

午餐

番茄山药鲜虾豆腐汤 + 米饭

碳水 米饭（略少）+ 山药蔬菜 番茄蛋白 鲜虾 + 豆腐脂肪 少量
食材
  • 鲜虾约 40–45g，去虾线
  • 嫩豆腐约 30g 切小丁
  • 番茄约 30g 去皮切碎
  • 山药约 20g 切小丁
  • 软米约 10–15g
  • 姜片；不加盐
做法
  1. 番茄少油炒出汁，加水下姜片、山药煮软。
  2. 下豆腐与虾，煮至虾全熟变色。
  3. 配少量软米饭。
  4. 不加盐、酱油、生抽。

虾务必全熟；豆腐选嫩易咽。主食略减。

下午餐

小馄饨 13 个 + 小油菜约 25–30g

碳水 馄饨皮蔬菜 小油菜蛋白 猪肉馅脂肪 少量
食材
  • 猪肉小馄饨（无盐自包冻货）13 个
  • 小油菜约 25–30g
做法
  1. 冷冻馄饨下开水，全部浮起后再煮 2–3 分钟，切开确认馅全熟。
  2. 小油菜焯软切碎，放汤里或另碟。
  3. 馄饨可对半切开练咀嚼。
  4. 汤里不加盐、酱油、紫菜虾皮调料。

务必用无盐自包冻货；市售成品多含盐，不选。

周日 10.11

清蒸鳕鱼 · 猪肝菠菜粥

鳕鱼 · 猪肝

早餐

胚芽米燕麦粥 + 水煮蛋 + 橙子两瓣

碳水 胚芽米 + 燕麦水果 橙子蛋白 全蛋脂肪 —
食材
  • 胚芽米约 10g
  • 即食燕麦约 5–8g
  • 鸡蛋 1 个（全蛋水煮）
  • 橙子两瓣去膜去籽
做法
  1. 胚芽米先煮软，下燕麦再煮片刻成粥。
  2. 水煮蛋全熟，可切小块或捣碎拌粥。
  3. 橙子去膜去籽，两瓣手抓或切小。
  4. 不加糖盐。

当天水果只橙子（两瓣，仅早餐）；下午为小馒头 + 蒸胡萝卜。蛋全熟。

午餐

清蒸鳕鱼 + 蒸娃娃菜 + 米饭

碳水 米饭（略少）蔬菜 娃娃菜蛋白 鳕鱼脂肪 少量油可淋
食材
  • 鳕鱼约 40–50g，去刺确认
  • 娃娃菜约 40–50g
  • 软米约 10–15g
  • 姜片；不加盐
做法
  1. 鳕鱼放姜片清蒸至全熟易碎，仔细剔刺。
  2. 娃娃菜蒸软切碎。
  3. 配少量软米饭，可淋极少量辅食油。
  4. 不加盐、酱油、生抽。

鳕鱼刺务必剔净；主食略减，鱼+菜为主。

下午餐

猪肝菠菜粥（米少菜多）

碳水 大米（少）蔬菜 菠菜（多）蛋白 猪肝脂肪 —
食材
  • 猪肝约 15–20g，去筋膜
  • 菠菜约 30–40g
  • 大米约 8–10g（米少）
  • 姜片少许；不加盐
做法
  1. 猪肝冷水浸泡去血水，焯烫后剁细。
  2. 大米先煮至半烂，下猪肝末煮至全熟。
  3. 菠菜焯水切碎后下锅，米少菜多，煮成稀粥。
  4. 不加盐、酱油、生抽；不放苹果。

本周主力补铁餐：猪肝量少、务必全熟；米少菜多。下午无苹果；橙子只在周日早餐两瓣。

注意事项

  • 本周主题：谷类略减、蔬菜+蛋白略增；自本周起每天早餐 / 午餐 / 下午餐三顿。按蕉蕉实际食量增减。
  • 蛋白排敏：周二约 1/4 个单独 → 周三约半个单独 → 周四起全蛋（周六、周日早餐水煮全蛋）；出现皮疹、呕吐、腹泻即停并就医。
  • 猪肝：周日下午猪肝菠菜粥（米少菜多），猪肝约 15–20g，务必全熟；本周主力补铁。
  • 减少叠蛋：周五下午改为南瓜百合双米粥（双米合计约 10g，不加盐糖），不再做香蕉蛋黄小饼。
  • 玉米饼份量：周五整批照做（面粉 50g），蕉蕉只吃 2–3 片（约合面粉 15–20g），其余大人吃。
  • 过敏观察：蛋白（二/三）、周四花生米糊（9.28 周已试过，仍观察 2–3 天，必须打细防呛）；新食物单独引入、观察 2–3 天。
  • 禁区：不加盐、糖、酱油、生抽；不安排酸奶；本周无蓝莓；不用婴儿盐/婴儿酱油。
  • 三文鱼 / 鳕鱼：必须全熟、仔细去刺；鳕鱼清蒸后剔刺再喂。
  • 馄饨：仅用无盐自包冻货，配小油菜约 25–30g；市售多含盐，不选。
  • 清水火锅（周一外出）：已吃；选无盐汤底，避免蘸料。
  • 奶量与补位：奶瓶改为 2 顿约 420ml（~06:00 180ml + ~19:15 240ml）；做菜用配方奶（周三奶香燕麦糊（配方奶）、周五奶香玉米饼（整批配方奶 100ml，蕉蕉 2–3 片约分到 30–40ml）、三文鱼蝴蝶面如用配方奶收汁也计入）和奶酪（周一奶酪土豆饼小圆一整块、周四/周五各半块）帮助补上与原约 600ml / 指南参考之间的差距。仅为家庭安排记录，不构成医疗建议。
  • 奶酪：一般每次半块入菜（周四牛肉饼、周五三文鱼面）；周一已吃小圆奶酪一整块。选用配料简单的原制/高钙奶酪，注意钠含量，仍整餐不加盐。
  • 水果：香蕉只在周三早餐；苹果在周四午餐牛肉饼 + 周六早餐粥（周四下午不放苹果）；橙子只在周日早餐两瓣，周日下午猪肝菠菜粥。苹果入菜均煮熟。
  • 维生素 D 400IU/天继续补；奶量约 420ml/天，分 2 顿：~06:00 约 180ml、~19:15 约 240ml（三餐辅食之后）。本页仅供家庭参考，不构成医疗建议。
