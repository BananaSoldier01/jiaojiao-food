本周情况

约 11 月龄，体重增长偏平台：午餐软饭提到约 20–25g，主餐辅食油约 5g，谷类约 60–80g/天左右。奶仍 2 顿约 420ml（~06:00 180ml + ~19:15 240ml）+ 维生素 D 400IU。奶酪入菜一般半块。本周周四下午牛肉小馄饨（原周日安排前移；周日下午改为苹果山药小黄米粥+鸡蛋羹）。周三农历生日：早番茄鸡蛋面、午青菜蒸饭+肉末茄子、下午酸奶巴斯克蛋糕小块。

本周重点 · 新食物与新做法

① 新引入：花菜（周日午餐清炒，观察过敏）、蛏子（周六午餐少量试几个，配牛肉时蔬焖饭；全熟去壳切小，观察）。② 新做法摘要：烘蛋（周五下午时蔬奶酪燕麦烘蛋，烤箱/空气炸烤至凝固全熟）；蓝莓松饼（周五早：蓝莓约 20–25g + 蛋约 1/2–1 + 配方奶约 30ml + 低筋粉约 15–20g，打糊小火煎 2–3 片）；酸奶巴斯克（周三下午：宝宝草莓香蕉酸奶+蛋+玉米淀粉，无糖，烤熟只给小块）。③ 无盐无糖无酱油无生抽。④ 牛肉小馄饨本周改周四下午（实吃）；周日下午为苹果山药小黄米粥+鸡蛋羹。

要买 / 常备

需买：鲜虾（周一虾丸+周二汤）、牛肉馅（周二饼+周六焖饭约35g+周四馄饨）、牛尾骨、三文鱼、比目鱼、蛏子（少量试几个）、口蘑、海鲜菇、花菜、丝瓜、生菜、西兰花、娃娃菜、小油菜、青菜、茄子、白萝卜、白菜、胡萝卜、西葫芦、玉米、南瓜、土豆、山药、番茄、洋葱、猕猴桃、香蕉、苹果、蓝莓、鸡蛋、奶酪、低筋面粉、玉米淀粉、宝宝酸奶、蝴蝶面/面条、小黄米、胚芽米、燕麦。常备：米、小米、黑米、花生、黑芝麻、核桃、小馒头、玉米馒头、配方奶、辅食油/核桃油。详见「采购」。

周一 10.12

南瓜小米糊 · 丝瓜玉米蒸虾丸 · 奶酪土豆饼

虾丸

早餐

南瓜小米糊 + 香蕉鸡蛋饼

碳水 小米约 10–12g + 少量面粉蔬菜/果 南瓜约 15–20g + 香蕉蛋白 全蛋脂肪 少量油
食材
  • 小米约 10–12g
  • 老南瓜约 15–20g，切小块
  • 香蕉适量压泥
  • 鸡蛋 1 个（全蛋）
  • 面粉少量 + 少量油；不加盐糖
做法
  1. 小米与南瓜加水煮至软烂，南瓜压碎拌匀成糊。
  2. 全蛋打散，加香蕉泥、少量面粉调成糊，少油小火摊成小饼，两面煎熟。
  3. 饼切条手抓；糊放温勺喂。不加盐糖。

小米约 10–12g、南瓜约 15–20g；香蕉鸡蛋饼用全蛋。不加盐糖酱油。

午餐

丝瓜玉米蒸虾丸 + 水煮生菜 + 软饭约 20–25g

碳水 软饭约 20–25g + 淀粉蔬菜 丝瓜 + 胡萝卜 + 玉米 + 生菜蛋白 虾泥脂肪 辅食油/核桃油约 5g
食材
  • 鲜虾去壳去虾线，剁成虾泥
  • 胡萝卜丁、玉米粒适量
  • 淀粉少许 + 辅食油适量搅粘
  • 丝瓜切片铺碗底
  • 生菜适量水煮软
  • 软米约 20–25g
  • 出锅核桃油/辅食油约 5g；不加盐、生抽
做法
  1. 虾泥 + 胡萝卜丁 + 玉米 + 淀粉 + 辅食油搅至粘墙（不加盐生抽）。
  2. 丝瓜片铺碗底/碗壁，虾糊搓丸摆上。
  3. 冷水上锅蒸约 25 分钟至全熟。
  4. 出锅淋核桃油/辅食油约 5g；配水煮软生菜与软饭约 20–25g。

虾务必全熟；图源步骤含盐生抽，蕉蕉版一律不加。主餐油约 5g，软饭约 20–25g（体重平台期微调）。

下午餐

奶酪土豆饼（奶酪半块）+ 猕猴桃

碳水 土豆 + 少量面粉水果 猕猴桃蛋白 蛋黄 + 奶酪半块脂肪 少量油
食材
  • 土豆适量，蒸软压泥
  • 蛋黄 1 个（或全蛋，按食量）
  • 奶酪半块，切碎
  • 面粉少量、葱花少许
  • 猕猴桃适量，去皮切小块
  • 少量油；不加盐
做法
  1. 土豆蒸软压泥，加蛋黄、奶酪碎（半块）、面粉、葱花拌匀成稠糊。
  2. 少油小火摊成小饼，两面煎熟，切条手抓。
  3. 猕猴桃去皮切小块或压泥同餐。
  4. 不加盐、酱油、生抽。

奶酪一般半块。本餐无强制配图（未找到清晰奶酪土豆饼步骤图，按文字做法即可）。

周二 10.13

鸡蛋水饼 · 苹果洋葱奶酪牛肉饼 · 娃娃菜虾仁海鲜菇豆腐汤

牛肉饼

早餐

鸡蛋水饼 + 玉米燕麦胚芽米粥

碳水 面粉 + 胚芽米 + 燕麦 + 玉米蛋白 全蛋脂肪 少量油
食材
  • 鸡蛋 1 个（全蛋）
  • 面粉少量 + 温水适量
  • 胚芽米约 8–10g
  • 即食燕麦约 5g
  • 玉米粒适量
  • 少量油；不加盐糖
做法
  1. 全蛋打散加温水、面粉调稀糊，少油小火摊薄水饼，两面熟透，切条。
  2. 胚芽米先煮软，下燕麦与玉米再煮片刻成粥。
  3. 不加盐糖。

水饼须熟透；粥可压碎调稀。

午餐

苹果洋葱奶酪牛肉饼（奶酪半块）+ 软饭约 20–25g + 水煮西兰花

碳水 软饭约 20–25g + 淀粉蔬菜 洋葱 + 西兰花水果 苹果（熟）蛋白 牛肉馅 + 奶酪半块
食材
  • 牛肉馅约 40–50g
  • 苹果适量切丁、洋葱切丁
  • 奶酪半块
  • 淀粉少许 + 辅食油约 5g
  • 西兰花适量焯/水煮软
  • 软米约 20–25g；不加盐
做法
  1. 苹果洋葱丁 + 牛肉馅 + 奶酪半块 + 淀粉 + 辅食油搅打上劲。
  2. 模具压饼，少油小火两面煎熟（切开无粉红）。
  3. 西兰花水煮/焯至软，切小。
  4. 配软饭约 20–25g。不加盐。

牛肉全熟；苹果入馅增湿软。软饭约 20–25g，主餐油约 5g。

下午餐

玉米馒头 + 娃娃菜虾仁海鲜菇豆腐汤

碳水 玉米馒头蔬菜 娃娃菜 + 海鲜菇蛋白 虾仁 + 豆腐脂肪 少量
食材
  • 玉米馒头 1 个（约 15–20g）
  • 鲜虾仁约 20–25g，去虾线切丁
  • 娃娃菜约 30–40g，撕小
  • 海鲜菇约 20–25g，切段
  • 嫩豆腐约 25–30g 切小丁
  • 少量油；不加盐
做法
  1. 虾去虾线切丁；娃娃菜撕小；海鲜菇切段；豆腐切丁。
  2. 海鲜菇焯约 1 分钟；虾焯至变色捞出。
  3. 少油炒软娃娃菜，加水煮开。
  4. 下菇、豆腐、虾再煮 3–5 分钟至虾全熟；汤里不加盐、酱油、生抽。
  5. 玉米馒头撕小块手抓。

虾务必全熟；豆腐选嫩易咽；海鲜菇焯透煮软。不加盐。

周三 10.14

农历生日 · 番茄鸡蛋面 · 肉末茄子 · 酸奶巴斯克

农历生日 · 巴斯克

早餐

番茄鸡蛋面（胡萝卜刻小花点缀，无盐）

碳水 面条蔬菜 番茄 + 胡萝卜小花蛋白 全蛋脂肪 少量油
食材
  • 面条适量煮软
  • 鸡蛋 1 个
  • 番茄适量去皮切碎
  • 胡萝卜刻小花点缀
  • 少量油；不加盐、酱油、生抽
做法
  1. 少油炒番茄出汁，倒入打散蛋液炒熟。
  2. 拌入煮软面条；胡萝卜刻小花焯软点缀。
  3. 全程不加盐糖酱油。生日快乐小装饰仅点缀。

农历生日早餐；无盐无酱油，胡萝卜小花只作点缀。

午餐

青菜蒸饭 + 肉末茄子（饭约 20–25g）

碳水 软饭约 20–25g蔬菜 青菜 + 茄子蛋白 猪肉末脂肪 辅食油约 5g
食材
  • 软米约 20–25g，可拌青菜碎蒸/焖
  • 猪肉末约 40–45g
  • 茄子约 40–50g 切小丁蒸软
  • 葱姜少许；辅食油约 5g；不加盐
做法
  1. 青菜焯软切碎，与米加水蒸/焖成软饭约 20–25g。
  2. 少油下肉末炒至变色全熟，下蒸软茄子丁翻匀，出锅可滴辅食油约 5g。
  3. 不加盐、酱油、生抽。

肉末务必全熟；茄子蒸软易咽。饭约 20–25g。

下午餐

酸奶巴斯克蛋糕（小块）

碳水 玉米淀粉蛋白 鸡蛋 + 宝宝酸奶脂肪 少量（酸奶）水果味 宝宝草莓香蕉酸奶自带
食材
  • 宝宝草莓香蕉酸奶适量
  • 鸡蛋 1 个
  • 玉米淀粉适量
  • 不放糖（甜味来自宝宝酸奶本身）
做法
  1. 宝宝草莓香蕉酸奶 + 蛋 + 玉米淀粉拌匀入模。
  2. 烤箱/空气炸至中心全熟、表面微上色。
  3. 放凉后只给一小块；不放糖、不加盐。

新做法·酸奶巴斯克：无糖，只用宝宝酸奶的天然甜；生日下午小块即可。本页非医疗建议。

周四 10.15

黑芝麻核桃米糊 · 三文鱼时蔬烩饭 · 牛肉小馄饨

三文鱼 · 馄饨

早餐

黑芝麻核桃米糊 + 小馒头

碳水 米 + 小馒头蛋白 —脂肪 黑芝麻 + 核桃
食材
  • 大米或小米约 10–12g
  • 熟黑芝麻碾碎少许
  • 核桃少量
  • 小馒头 1–2 个
做法
  1. 米煮软，加黑芝麻与核桃打成细糊，调稀。
  2. 小馒头撕小块手抓。
  3. 不加糖；芝麻核桃须碾细防呛。

糊要细、无颗粒；不加糖。

午餐

三文鱼时蔬烩饭（三文鱼约 40–50g，饭约 20–25g，油约 5g）

碳水 软饭约 20–25g蔬菜 时蔬（胡萝卜/西兰花/玉米等）蛋白 三文鱼约 40–50g脂肪 DHA + 辅食油约 5g
食材
  • 三文鱼约 40–50g，去皮去刺切小丁
  • 软米约 20–25g
  • 时蔬丁（胡萝卜、西兰花、玉米等）适量
  • 辅食油约 5g；不加盐、任何调味
做法
  1. 少油下三文鱼丁炒至全熟变色，下时蔬丁翻软。
  2. 与软饭约 20–25g 轻轻烩匀，出锅补辅食油约 5g。
  3. 仔细确认无刺；不加盐、酱油、生抽。

三文鱼必须全熟去刺；饭约 20–25g，油约 5g。

下午餐

牛肉小馄饨 + 小油菜约 25–30g

碳水 馄饨皮蔬菜 小油菜约 25–30g蛋白 牛肉馅（无盐自包）脂肪 少量
食材
  • 牛肉馅无盐自包（个数按蕉蕉食量）
  • 小油菜约 25–30g
  • 清水；汤里不加盐/酱油/紫菜虾皮
做法
  1. 自包牛肉小馄饨下开水，浮起后再煮 2–3 分钟，切开确认全熟。
  2. 小油菜焯软切碎。
  3. 全程不加盐、酱油、生抽。市售含盐馄饨不选。

本周周四下午牛肉小馄饨（实吃）；个数按食量，无盐自包。

周五 10.16

蓝莓松饼 · 清炖牛尾骨时蔬 · 时蔬奶酪燕麦烘蛋

蓝莓松饼 · 烘蛋

早餐

蓝莓松饼（2–3 片）+ 宝宝酸奶一小份

碳水 低筋面粉约 15–20g水果 蓝莓约 20–25g蛋白 蛋约 1/2–1 + 宝宝酸奶脂肪 配方奶约 30ml + 少量油
食材
  • 蓝莓约 20–25g
  • 鸡蛋约 1/2–1 个
  • 配方奶约 30ml
  • 低筋面粉约 15–20g
  • 宝宝酸奶一小份
  • 少量油；不加盐糖
做法
  1. 蛋、配方奶、蓝莓入辅食机搅打约 3 分钟至体积约 1.5 倍。
  2. 加入低筋面粉搅拌至无干粉颗粒。
  3. 不粘锅最小火，舀一勺面糊摊成 2–3 片；表面冒泡后翻面，两面煎熟。
  4. 配宝宝酸奶一小份；不加盐糖。

新做法·蓝莓松饼：蓝莓约 20–25g、蛋约 1/2–1、配方奶约 30ml、低筋粉约 15–20g，做 2–3 片。图源分量可作参考，以蕉蕉分量为准。

午餐

清炖牛尾骨时蔬（洋葱胡萝卜苹果土豆）+ 软饭约 20–25g

碳水 软饭约 20–25g + 土豆蔬菜/果 洋葱 + 胡萝卜 + 苹果蛋白 牛尾（软烂剔骨）脂肪 汤油 + 可补辅食油约 5g
食材
  • 牛尾骨适量（可先泡水解冻）
  • 洋葱切片少许
  • 胡萝卜切块
  • 苹果切块（带皮可，喂前确认软烂）
  • 土豆切块
  • 少量油；清水；不加盐、酱油、生抽
  • 软米约 20–25g
做法
  1. 牛尾骨泡水解冻；少油下锅把牛尾骨煎一下至表面变色。
  2. 倒入洋葱炒香，再放入胡萝卜、苹果、土豆翻匀。
  3. 所有食材放入炖锅，倒入适量清水，小火炖至牛尾软烂、蔬果软透。
  4. 肉剔骨后撕碎/切小；蔬果压软或切小；汤底不加盐。可补辅食油约 5g。
  5. 配软饭约 20–25g；汤可少许拌饭。

牛尾务必软烂剔骨再喂；汤底无盐。步骤跟小红书，调味按家里无盐无酱油改写。

做法
