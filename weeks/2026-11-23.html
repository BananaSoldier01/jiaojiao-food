周一 11.23

南瓜小米粥 · 彩椒牛肉饼 · 胡萝卜西兰花烘蛋

彩椒牛肉饼 · 烘蛋

早餐

南瓜小米粥 + 半个水煮蛋 + 橙子

碳水 小米蔬菜 南瓜水果 橙子蛋白 半个水煮蛋
食材
  • 小米约 10–15g
  • 老南瓜约 30g，去皮切小块
  • 鸡蛋，水煮至全熟，本餐取半个
  • 橙子适量（可按往期两瓣），去膜去籽
做法
  1. 小米与南瓜一起煮至软烂，南瓜压碎拌匀；不加盐糖。
  2. 水煮蛋至全熟，取半个切小块或捣碎同餐。
  3. 橙子去膜去籽，切小或瓣手抓同餐。

蛋须全熟，本餐半个。橙子去膜去籽切小。不加盐糖。

午餐

彩椒牛肉饼 + 软饭约 20–25g + 清蒸小青菜

碳水 软饭约 20–25g蔬菜 彩椒 + 小青菜蛋白 牛肉馅约 40–50g脂肪 辅食油合计约 5g
食材
  • 牛肉馅约 40–50g
  • 彩椒适量，切碎/擦丝
  • 玉米淀粉少许（用于上劲/定型）
  • 辅食油合计约 5g（含煎用油）；不加盐、酱油、生抽、糖、宝宝酱油
  • 软米约 20–25g（生米）
  • 小青菜适量
做法
  1. 牛肉馅与彩椒碎、玉米淀粉少许搅匀上劲（全程不加盐糖酱油/生抽/宝宝酱油）。
  2. 压成小饼，少油小火两面煎至全熟（切开无粉红）；整餐辅食油合计约 5g（含煎用油；不足再补足，勿另加一份 5g）。
  3. 配软饭：生米约 20–25g 煮软。
  4. 小青菜蒸/焯至软，切小同餐。

做法同往期 10.30、11.05 彩椒牛肉饼。不加任何酱油生抽盐糖；牛肉务必全熟。软饭生米约 20–25g。

下午餐

胡萝卜西兰花烘蛋（含燕麦；奶酪半块，约 40ml 鲜奶）

碳水 燕麦蔬菜 胡萝卜 + 西兰花蛋白 全蛋 + 奶酪半块脂肪 奶酪 + 鲜奶
食材
  • 鸡蛋 1 个
  • 即食燕麦约 8–10g
  • 奶酪半块，切碎
  • 胡萝卜、西兰花适量，切丁，焯软
  • 悦鲜活鲜奶约 40ml
  • 不加盐
做法
  1. 蛋打散，拌入燕麦、奶酪碎、焯软的胡萝卜和西兰花丁，以及鲜奶约 40ml。
  2. 倒入耐烤模具，烤箱/空气炸烤至表面凝固、中心全熟。
  3. 放温切小块；不加盐糖酱油。

本餐按往期时蔬奶酪燕麦烘蛋（11.04）做，蔬菜固定为胡萝卜和西兰花。含燕麦；奶酪半块；鲜奶约 40ml，不替代配方奶瓶。中心无流心再喂。本餐为全蛋，早餐已有半个水煮蛋。

周二 11.24

粗粮吐司 · 番茄三文鱼蝴蝶面 · 银耳百合汤

三文鱼蝴蝶面

早餐

粗粮吐司 + 黑芝麻核桃米糊 + 半个水煮蛋

碳水 吐司 + 米蛋白 半个水煮蛋脂肪 黑芝麻 + 核桃
食材
  • 粗粮吐司适量（可买成品；先看配料）
  • 大米或小米约 10–12g
  • 熟黑芝麻碾碎少许
  • 核桃少量
  • 鸡蛋，水煮至全熟，本餐取半个
做法
  1. 若买成品，先看配料，含盐含糖的少给或不选；可撕小块手抓，可略放温。
  2. 米煮软，加黑芝麻与核桃打成细糊，调稀；芝麻核桃须碾细防呛。不加盐糖。
  3. 水煮蛋至全熟，取半个切小块或捣碎同餐。

粗粮吐司为本周新增，买的先看配料。芝麻核桃碾细防呛。蛋须全熟，本餐半个。不加盐糖。

午餐

番茄三文鱼蝴蝶面（三文鱼约 40g）

碳水 蝴蝶面蔬菜 番茄蛋白 三文鱼约 40g脂肪 DHA + 少量油
食材
  • 三文鱼约 40g，去皮去刺
  • 番茄适量，煮软压成泥
  • 蝴蝶面约 25g，煮软
  • 少量油；不加盐、酱油、生抽
做法
  1. 三文鱼薄涂油小火香煎至全熟，仔细去刺，压碎或切小，去掉焦脆硬边。
  2. 番茄煮软压成泥，与三文鱼拌匀。
  3. 蝴蝶面煮软后拌入番茄三文鱼泥。不加盐、酱油、生抽。

做法同往期 09.24；三文鱼按约 40g（往期该餐写约 25–30g）。须全熟、仔细去刺。鱼虾只放午餐。

下午餐

银耳百合汤 + 一个小馒头

碳水 银耳羹 + 小馒头蔬果 百合蛋白 —脂肪 —
食材
  • 银耳适量，提前泡发，撕小朵（往期未写用量，不补造克数）
  • 百合适量，撕瓣（往期未写用量，不补造克数）

按往期 11.15 银耳百合来，不放雪梨、不加糖。百合炖软，银耳炖出胶。市售小馒头看配料，含盐含糖不选。

牛尾汤

早餐

苹果山药小黄米粥 + 水煮蛋

碳水 小黄米 + 山药水果 苹果蛋白 全蛋
食材

  • 苹果约 20g，去皮去核切小块
  • 山药约 20g，去皮切小块

午餐

胡萝卜白萝卜炖牛尾汤

碳水 —蔬菜 胡萝卜 + 白萝卜蛋白 牛尾（软烂剔骨）脂肪 汤油 + 辅食油合计约 5g
食材
  • 牛尾骨适量（可先泡水解冻）
  • 胡萝卜切块
  • 白萝卜切块
  • 姜片；清水；不加盐、酱油、生抽
做法
  1. 牛尾骨泡水焯烫；与胡萝卜、白萝卜、姜片加水，小火炖至牛尾软烂、萝卜软透。
  2. 肉剔骨后撕碎/切小，只给肉，检查碎骨。汤底不加盐、酱油、生抽。
  3. 整餐辅食油合计约 5g（含汤油；不足再补足，勿另加一份 5g）。

往期没有同名整餐，按本次指定的胡萝卜、白萝卜与牛尾炖汤。牛尾务必软烂剔骨再喂，只给肉。往期牛尾午餐常配软饭，可拌一点；本餐标题不单列米饭。

牛油果酸奶 + 小馒头（不放蓝莓）

碳水 小馒头水果 牛油果蛋白 宝宝酸奶脂肪 牛油果
食材
  • 无糖宝宝酸奶适量
  • 牛油果适量，压泥

按往期蓝莓牛油果酸奶去掉蓝莓。须与牛油果拌着吃，不单独一大杯纯酸奶。不替代配方奶瓶。市售小馒头看配料。

周四 11.26

华夫饼 · 河虾豆腐羹 · 牛肉小馄饨

河虾 · 馄饨

早餐

华夫饼 + 牛奶 + 水煮蛋 + 常温香蕉

碳水 华夫饼水果 香蕉蛋白 水煮蛋脂肪 鲜奶
食材
  • 华夫饼适量（可买成品或家做）
  • 悦鲜活鲜奶适量（放温；不替代配方奶）
  • 鸡蛋 1 个（全蛋水煮）
  • 香蕉适量，去丝，切小，常温直接吃（不蒸）
做法
  1. 若买成品，先看配料，含盐含糖的少给或不选；若家做，不加盐不加糖，按食量。可撕小块手抓。
  2. 悦鲜活鲜奶放温后适量给一点；不加糖；不替代配方奶瓶。
  3. 水煮蛋至全熟，切小块或捣碎同餐。
  4. 香蕉去丝，切小，常温直接吃，不蒸。

鲜奶只配一点，不替代早晚两瓶配方奶。蛋须全熟。华夫饼含盐含糖的少给或不选。不加盐糖。

午餐

番茄鲜虾豆腐山药羹 + 米饭（虾用河虾）

碳水 软饭约 20–25g + 山药蔬菜 番茄蛋白 河虾 + 豆腐脂肪 辅食油合计约 5g
食材
  • 河虾约 40–45g，去壳去虾线（往期此菜写鲜虾约 40–45g，本周用河虾）
  • 嫩豆腐约 30g，切小丁
  • 番茄约 30g，去皮切碎
  • 山药约 20g，切小丁
  • 姜片；辅食油合计约 5g（含炒用油）；不加盐
  • 软米约 20–25g（生米）
做法
  1. 番茄少油炒出汁，加水下姜片、山药煮软。
  2. 下豆腐与河虾，煮至虾全熟变色；整餐辅食油合计约 5g（含炒用油；不足再补足，勿另加一份 5g）。
  3. 配软饭：生米约 20–25g 煮软；羹可少许拌饭。

做法同往期 11.02 番茄鲜虾豆腐山药羹，虾改用河虾。虾须去壳去线、切小、煮至全熟。鱼虾只放午餐。不加盐、酱油、生抽。软饭生米约 20–25g。

下午餐

牛肉小馄饨（自包，个数按食量）+ 青菜

碳水 馄饨皮蔬菜 青菜蛋白 牛肉馅脂肪 —
食材
  • 牛肉馅无盐自包（个数按蕉蕉食量）
  • 清水；汤里不加盐/酱油/紫菜虾皮
  • 青菜约 25–30g（小油菜/小青菜等）

  2. 青菜焯软切碎。
  3. 全程不加盐、酱油、生抽。市售含盐馄饨不选。

馄饨自包无盐，切开确认全熟；个数按食量。本周只这一次。

猪肝烩饭

早餐

牛奶蛋花粥（往期作牛奶蛋花燕麦粥）

碳水 燕麦蛋白 蛋花 + 奶脂肪 奶
食材
  • 即食燕麦约 10–12g
  • 配方奶或牛奶适量（约 80–100ml，煮粥用；非替代奶瓶两顿）
  • 鸡蛋 1 个，打散淋蛋花
做法
  1. 燕麦加水或少量配方奶煮软，边搅边淋入蛋液成蛋花，再补适量配方奶/牛奶调成粥；蛋须全熟。
  2. 不加盐糖。本餐不放蓝莓。

往期全名是牛奶蛋花燕麦粥，含燕麦。蛋花须全熟；本餐用 1 个蛋。早餐用奶不替代奶瓶。不加盐糖。

午餐

猪肝洋葱胡萝卜玉米粒烩饭（胚芽米 25g + 猪肝 30g）

碳水 胚芽米 25g（生重）蔬菜 洋葱 + 胡萝卜 + 玉米粒蛋白 猪肝 30g
食材
  • 胚芽米 25g（生重）
  • 猪肝 30g，去筋膜
  • 洋葱、胡萝卜、玉米粒（记录未写用量）
  • 不加盐、酱油、生抽
做法
  1. 猪肝冷水浸泡去血水，焯烫后切小或剁细。
  2. 胚芽米 25g 煮成软饭；洋葱、胡萝卜、玉米粒煮软或炒软，与猪肝烩入软饭，猪肝须全熟。
  3. 不加盐、酱油、生抽。

按 11.09 记录：胚芽米 25g、猪肝 30g。洋葱、胡萝卜、玉米粒往期未写用量，不补造克数。猪肝务必全熟。本周猪肝只这一次。

下午餐

奶香小馒头 + 热拌菠菜 + 山药茯苓糊糊（不二宝贝）

碳水 馒头 + 糊糊蔬菜 菠菜蛋白 —脂肪 牛奶和面
食材
  • 面粉适量；牛奶适量（用于和面）
  • 不加盐、不加糖
  • 菠菜适量
  • 少量油；不加盐
  • 不二宝贝山药茯苓糊糊 1 份（按包装冲调）
做法
  1. 用牛奶和面，家做小馒头，不加盐不加糖，按食量蒸熟；放温撕小块手抓。
  2. 菠菜焯水至软，沥干切碎，少油、无盐，趁热拌。
  3. 不二宝贝山药茯苓糊糊按包装用温水冲开调稀，放温同餐。

奶香小馒头为新增，用牛奶和面，家做不加盐不加糖。热拌菠菜按往期凉拌菠菜处理：焯软切碎，少油无盐，趁热拌。糊糊调稀防呛。不替代配方奶瓶。

注意事项

  • 本周约定：有米饭的午餐，软米按生重约 20–25g；不加盐、不加糖、不加酱油/生抽/宝宝酱油；主餐辅食油合计约 5g。周一至周五已定，周六、周日先待定。
  • 正在厌奶：把鲜奶、奶酪、酸奶、豆腐和鱼虾多排进辅食，帮助补钙。早晚两瓶配方奶仍可少量试，不硬灌。餐里的鲜奶、奶酪、酸奶不替代配方奶瓶。维生素 D 400IU 继续补。本页非医疗建议。
  • 烘蛋含燕麦：周一下午胡萝卜西兰花烘蛋按往期时蔬奶酪燕麦烘蛋做，含燕麦（即食燕麦约 8–10g），另有奶酪半块和约 40ml 鲜奶；蔬菜用胡萝卜和西兰花，须焯软。中心无流心再喂。
  • 鱼虾放午餐：周二三文鱼、周四河虾均在午餐。三文鱼约 40g，须全熟、仔细去刺。河虾去壳去线、切小、煮至全熟。
  • 牛尾剔骨：周三午餐胡萝卜白萝卜炖牛尾汤，牛尾须炖至软烂，剔骨撕碎，只给肉，检查碎骨。往期常配软饭，可拌一点。
  • 猪肝须全熟：周五午餐猪肝洋葱胡萝卜玉米粒烩饭按 11.09：胚芽米 25g、猪肝 30g。猪肝冷水浸泡去血水，焯烫后切小或剁细，烩入软饭须全熟。本周猪肝只这一次。
  • 热拌菠菜：周五下午菠菜焯软切碎，少油、无盐，趁热拌。
  • 牛肉小馄饨：周四下午自包无盐，切开确认全熟；个数按食量。本周只这一次。市售含盐馄饨不选。
  • 粗粮吐司与华夫饼：周二早餐粗粮吐司、周四早餐华夫饼，买的先看配料，含盐含糖的少给或不选；家做不加盐不加糖。
  • 奶香小馒头：周五下午用牛奶和面，家做不加盐不加糖，按食量。
  • 牛油果酸奶：周三下午不放蓝莓，用无糖宝宝酸奶与牛油果泥现拌，不单独给纯酸奶。
  • 牛奶蛋花粥：周五早餐往期全名是牛奶蛋花燕麦粥，含燕麦；用 1 个蛋做成蛋花，须全熟。不放蓝莓。用奶不替代配方奶瓶。

  • 周六、周日：先待定，确定后再更新本页和采购。
  • 食量与观察：按实际食量喂。如有发热、腹泻不止、大便带血、尿明显变少或精神变差，及时就诊。
  • 本页非医疗建议：仅供家庭辅食安排参考；如有生长曲线、肠胃或过敏问题，请咨询儿科医生。
